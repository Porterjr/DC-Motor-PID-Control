# DC-Motor-PID-Control
基于STM32F103的直流电机PID闭环调速系统

## 硬件
- STM32F103C8T6最小系统板
- TB6612电机驱动
- JGA25-370 6V减速电机（带霍尔编码器）
- 0.96寸OLED（I2C）
- 18650电池盒（7.4V）待到货，目前USB供电
